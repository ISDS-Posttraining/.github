# ISDS-Posttraining

서강대학교 ISDS Lab 멤버들이 post-training 관련 논문을 직접 재현하고 결과를 정리하는 공간입니다.
각 레포는 논문 하나를 다루며, 원 논문 수치와 재현 수치를 함께 기록합니다.
